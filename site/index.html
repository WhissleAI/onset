How it works

Most of the meaning arrives before you finish talking. Onset reads it as it arrives and starts the free lookups early; the one paid search waits until the meaning is final.

  • Hears how you ask. Whissle Arc reads the audio itself (who is speaking, corrections, whether you're done) alongside the words.
  • Searches while you speak. The 10M-parameter Arc Tagger re-reads the partial sentence at about 0.7 ms per word, so lookups can start on word three.
  • Remembers context. A local memory graph resolves “it”, “there” and “the old one” before anything is searched.
  • Pays last. Cards, facts, saved answers and site docs are free. Paid web search runs once, only when they can't answer.

The six problems, one number each

Private by default

Your memory, history and index never leave your Mac.

Stays on your Mac
Arc audio models, the Arc Tagger, the reranker, the memory graph, the Keystone answer store and every cache. All in ~/Library/Application Support/Onset.
Leaves only when needed
Audio to Deepgram when a Deepgram key is set (the Flux ear). The final search query to Tavily or Telem when no free lane can answer. The question and its sources to Claude for the written answer.
Never sent
Your memory graph, past questions, or a profile of you. Masked words never reach search, memory or logs. Keys live in the macOS Keychain.
